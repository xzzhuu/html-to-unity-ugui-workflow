# HTML UI 转换示例

这些目录保存外部 HTML 与图片清单，用于检查通用导入器的结构转换。它们不是 Skill 文档，也不包含业务 Presenter。

[浏览器演示截图 / Screenshot gallery](../docs/screenshots/README.md)：四个示例的真实 HTML 预览，含塔吊设备切换与库存条目选择状态。截图不是 Unity 运行或视觉验收证据。

- `TowerCrane/html/TowerCraneDashboardPanel.html`：布局较复杂，含动态 Item Prefab 和仅供浏览器预览的示例数据。
- `Inventory/html/InventoryPanel.html`：库存布局及动态 Item 模板。
- `Settings/html/SettingsPanel.html`：表单控件。
- `Starter/html/StarterPanel.html`：新目录初始化器生成的未审核草稿。

共享工作流、提示词和流程图只在全局 [ui-panel-design-to-html Skill](../Skills/ui-panel-design-to-html/SKILL.md) 中维护。TowerCrane 的专属示例信息见 [TowerCrane README](TowerCrane/README.md)；各示例的 `elements.json`、`sprites.json` 是转换输入，不是重复文档。
