# 分阶段提示词

使用实际文件与真实确认意见替换方括号。已有适用确认不重复索取；未经确认不自动越过阶段。

## 只初始化

```text
$ui-panel-design-to-html 请以“新文件目录”初始化 [路径] 的 [PanelName] 工作区，默认布局 1920×1080，模式为 [full/visual-only]。保留已有文件，不生成业务控件或审批证据，仅报告创建/保留结果与可用入口。
```

## 从面板预览开始

```text
$ui-panel-design-to-html 请根据 [当前需求/原有面板] 制作面板预览，仅包含实际需要的组件和状态。优先复用现有 Sprite，保持源图像素细节，布局默认 1920×1080。先停在“面板预览图确认”，不提前导出正式素材或进入导入步骤。
```

## 面板确认后制作元素组图

```text
$ui-panel-design-to-html 我确认 [面板预览版本]，意见为 [真实原文]。请仅制作当前需要的可复用元素组图，各组独立可调整，展示原生组件拼接效果和必要状态。同形仅颜色不同共用白色/中性素材，用 Image.color 改色；素材及组图以组件缩写开头，保持原始分辨率。完成后停在“元素组图确认”。
```

## 完整分支继续

```text
$ui-panel-design-to-html 我确认 [元素组图及版本]，意见为 [真实原文]。请导出对应素材，再完成 HTML 和浏览器验收；需要的 Unity 导入使用项目既有转换器及 MCP。保留原生组件、可编辑 TMP 与原有绑定，不为视觉效果创建或修改 C#。记录 HTML 就绪与 Unity 导入结果，分别说明真实验证范围。
```

## 仅视觉优化

```text
$ui-panel-design-to-html 只优化 [原有面板] 的视觉。先确认面板预览，再确认实际所需的元素组图；两项确认后，保持原始素材像素，用组件缩写命名中性素材，直接通过 Unity MCP 导入并替换原 Prefab。不要生成 HTML/CSS/JS，不使用转换器、不创建 C#、主题资产或额外组件库。保留 GUID、业务绑定和交互，交付元素素材与面板预制体，以及外部验收截图。
```

## 审核已有成果

```text
$ui-panel-design-to-html 请按工作区实际模式审核 [目录]：核对面板及元素组图确认版本、实际所需类型覆盖、组件缩写前缀、颜色复用、原始/导出像素尺寸和原生拼接效果。完整分支再检查 HTML；仅视觉分支检查 Unity MCP 替换证据。没有真实确认或验证时保持未就绪。
```

共用补充要求：所有元素素材贴图宽高均用 2 的幂次方，保持图形细节与原布局；确认后把元素组图和每个完整面板预览也通过 MCP 导入 Unity 的 DesignReferences 独立目录，保留原分辨率，不作为运行时面板整图。

正式面板预览规则：每个面板单独输出，画布使用纯色背景，不叠加场景、照片、纹理、棋盘格等干扰；在面板主体外标注画布宽×高和主体宽×高。默认画布 1920×1080；素材 POT 像素尺寸不约束 RectTransform 布局尺寸，也不要求预览图改成 POT。确认后将组图和完整面板预览原分辨率导入 Unity 独立参考目录。

纯色画布配色要求：画布背景必须与面板主体/元素图片主色明显区分，让边界、圆角和透明效果清楚可见；深色面板可使用中性灰底。不同面板可以使用相同的对比底色，不要求各自采用不同颜色。

VR 素材约束：各元素均使用无边缘描线的填充造型，不制作按钮/底板/内衬等细轮廓或额外 Outline 素材；通过填充色、明暗、透明度与留白表达层级及状态。装饰性细分隔线改用留白。九宫格切片边距和审核尺寸标注线保留；去描边不等于已完成设备抗锯齿验收。
