# 项目总体流程

以星港拾荒者的六页制作流程为唯一项目示例。源包在工程外的 `Workspaces/StarportSalvage/Panels/{PanelName}/`；共享素材、批准记录与工具留在游戏根目录。

1. 核对需求，确认完整面板预览，再确认实际需要的元素组图。
2. 导出素材，维护游戏根 `project.assets.json`，制作 XHTML、清单与浏览器预览，完成 HTML 验收。
3. 在 **Tools → HTML to UGUI → 导入整个项目...** 选择游戏根，先核对只读计划，再导入 `Assets/HtmlToUGUIStage/StarportSalvage`。
4. 使用项目现有 PICOSansVFESC SDF 和共享材质，完成原生圆角、Slider 装配及同数据集的 Unity/HTML 图像对照。
5. 查看复制计划，主面板和 Item 复制到 `Assets/Art/UIPrefab/StarportSalvage`，图片复制到 `Assets/Art/UI/Sprites/StarportSalvage`；重验正式副本。
6. 执行仓库 `Tools/verify-starport-panels.py --unity-project UnityProject`，核对两处资源、字体、引用和交付指纹。

当前正式产物为六个主面板、四个 Item 和 24 张共享图片。StageScene 保存示例数据快照供逐页预览；游戏层仍负责数据、导航、事件、设置服务和结算。没有新增面板视觉脚本。

完整 [制作流程](../../../docs/game-example/workflow.md)、[实际视觉对照和转换规范](../../../docs/game-example/conversion-rules.md) 与 [工程说明](../../README.md) 为现行入口。旧 Example 三面板已经删除，历史整理报告仅作为发生时的记录。
